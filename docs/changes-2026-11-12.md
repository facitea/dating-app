## 기능과 정책
- 서비스 보상은 기존 알림함과 함께 미확인 알림 팝업으로 표시, 확인 후 읽음 처리.
- Firebase 인증 계정이 이미 존재하면 기존 비밀번호가 필요하며 재설정 경로 안내. 인증된 탈퇴 회원은 기존 회원 ID로 재가입 심사를 진행한다. 정지·신원 차단·신고 기록은 유지하며 예전 매칭을 자동 재개하지 않는다. 이메일 인증 계정 자체를 삭제하거나 임의로 비밀번호를 변경하지 않는다.
- 신규 가입 5코인 1회 지급. 재가입에는 다시 지급하지 않음. 기존 회원 일괄 지급은 하지 않음.
- 테스트 상품: 10코인 1,200원 / 50코인 5,000원 / 150+30코인 15,000원 표시. 결제 없이 테스트 코인 지급.
- 추가 인연 3코인, 신규 유료 대화 요청 20코인. 기존 방은 추가 차감하지 않으며 미수락/거절/상호 좋아요 시 기존 환불 정책 유지.
- 신고 결과 알림에 신고자와 신고 대상자 구분. 설정의 이메일 비밀번호 재설정 진입 경로 제공. 기존 LOCAL 비밀번호 변경 기능 유지.
- 채팅은 IME 조합 중 input의 실제 값을 읽어 마지막 글자 누락 방지. 채팅방 안에서는 하단 탭과 알림 상단 바 숨김.
- 관심사·취미 62개 기본 선택지와 직접 입력(항목 30자, 최대 10개). 기존 성향 저장·심사·추천 조건·상대 프로필 표시 경로를 공유한다.
- 최근 접속은 인증된 요청 시 약 5분 간격으로 기록하고 프로필 열람 권한이 있는 상대에게 표시.
- 받은 좋아요: 좋아요 / 싫어요 / 지우기. 싫어요는 수신 좋아요 거절, 지우기는 수신 목록 숨김. 상대 차단과는 별개. 실제 받은 목록을 표시했을 때만 읽음 요청, 발신자에게 확인 여부 표시.
- 커뮤니티: 고민 상담/연애 이야기/일상, 게시글·댓글·본인 삭제·신고, 20개씩 목록, 최근 댓글 50개. 활동 회원만 접근, 차단/신고로 접촉 제한된 회원 콘텐츠 제외. 작성 간격 10초, 글·댓글 합계 하루 100개 제한.
- 관리자 커뮤니티 신고 메뉴: OWNER/SUPPORT만 신고 조회 및 게시물 숨김/공개. 조치 API는 기존 CSRF 및 감사 로그 적용.
- 사진 안내: 첫 대표사진은 눈·코·입이 선명한 사진, 이후 가림/전신 사진 가능. 자동 얼굴 판별·자동 순서 변경을 새로 구현한 것은 아님.
- 지인 차단은 요청에 따라 정식 출시 전 할 일로 남김.
